# 바삭 (BASAK) - 충남대학교 대덕캠퍼스 낙엽 큐레이션 웹 앱 🍂

> **"오늘 궁동 캠퍼스의 낙엽은 얼마나 바삭할까?"**  
> 충남대학교 대덕캠퍼스 학생들을 위한 실시간 기상청 데이터 기반 낙엽 바삭함 및 적재량 큐레이션 반응형 웹 애플리케이션입니다.

---

## 🌟 핵심 기능 및 특징

1. **기상청 초단기실황 API (`getUltraSrtNcst`) 실시간 연동**
   - 대전광역시 유성구 궁동 충남대학교 대덕캠퍼스 고정 격자 좌표 (`nx: 67, ny: 100`)
   - 기상청 실황 발표 주기(매시 10분 생성)에 맞춘 `base_date`, `base_time` 자동 동기화
   - 실시간 기온(`T1H`), 습도(`REH`), 풍속(`WSD`), 강수형태(`PTY`), 1시간 강수량(`RN1`) 수신
   - `vite.config.js` 프록시(`/api/kma`)를 통한 안전한 CORS 우회

2. **기상학적 실효습도($H_e$) 기반 바삭함 수치 모델링**
   - **실효습도 공식**:  
     $$H_e = (1 - r) \sum_{i=0}^{4} r^i H_i \quad (r = 0.7)$$  
     현재 실시간 습도($H_0$)와 가을철 누적 습도 가중치를 반영하여 낙엽 내부의 수분 함유량을 과학적으로 추정
   - **실시간 기상 보정**:
     - 강수 시(`PTY > 0` 또는 `RN1 > 0`): 바삭함 지수를 15% 이하로 즉시 하향 (낙엽 수분 포화 및 미끄럼)
     - 건조 가산/감점: 풍속(`WSD`)에 의한 증발 가산점, 온화한 가을 기온(`T1H`) 건조 보너스, 상대습도 70% 초과 감점 반영
   - **3단계 상태 등급**:
     - `0~30%`: 눅눅함 (소리 없음, 미끄럼 주의)
     - `31~70%`: 적당함 (은은하게 밟히는 상태)
     - `71~100%`: 최상의 바삭함 (경쾌한 ASMR 수준)

3. **낙엽 적재량 지수 (1~3단계)**
   - 가을 시즌 진행도(10~11월 피크)와 풍속(`WSD`)을 결합하여 `1단계(듬성듬성)`, `2단계(소복소복)`, `3단계(수북수북)` 자동 산정

4. **충남대학교 4대 핵심 구역별 공간 보정**
   | 구역명 | 주요 수종 | 일조 보정계수 | 구역 특성 및 안전 기능 |
   | :--- | :---: | :---: | :--- |
   | **중앙도서관 앞 광장 ~ 백마교** | 플라타너스 | `1.2` | 개활지로 건조 속도 1위, 바삭함 특화 코스 |
   | **한누리회관 뒤편 메타세쿼이아 길** | 메타세쿼이아 | `0.75` | 그늘진 숲길, 바삭함 대신 **'푹신함 지수'** 표시 |
   | **영탑지 및 농대 주변 산책로** | 벚나무·단풍나무 | `0.95` | 잔잔한 호수와 어우러진 고즈넉한 사색 코스 |
   | **공과대학 ~ 자연대학 경사로 언덕길** | 은행나무 | `0.85` | **바삭함 지수 30% 이하 시 '경사로 미끄럼 주의' 빨간색 경고 배지 자동 발동** |

5. **감성적인 가을 디자인 & 인터랙션**
   - 따뜻한 가을 테마 팔레트: 웜 베이지(`FAF6F0`), 테라코타 오렌지(`D96B27`), 딥 포레스트 그린(`2D4739`), 골든 옐로우(`E5A93C`)
   - 480px 모바일 뷰포트 레이아웃
   - **Web Audio API 기반 낙엽 바스락(ASMR) 효과음 합성기** 내장 (사운드 On/Off 토글 지원)
   - 각 구역 카드 클릭 시 코스 상세 팁, 벤치 위치, 추천 방문 시간 모달 제공

## 🛠️ 기술 스택

- **Frontend:** React 18, Vite 6, Tailwind CSS 3, Lucide Icons
- **Audio Engine:** Web Audio API (합성 노이즈 & 밴드패스 필터링)
- **API:** 대한민국 기상청 초단기실황조회 서비스 (`VilageFcstInfoService_2.0`)

## 🚀 실행 및 배포 방법

### 1. 로컬 개발 환경
```bash
# 의존성 설치
npm install

# 로컬 개발 서버 실행 (기상청 API 프록시 포함)
npm run dev

# 프로덕션 빌드
npm run build
```
웹 브라우저에서 `http://localhost:5173/`으로 접속하여 실시간 연동 상태를 확인하실 수 있습니다.

### 2. Vercel 배포 방법
프로젝트 루트에 `vercel.json` 프록시 리라이트 설정이 이미 완비되어 있습니다.
1. GitHub 저장소에 코드를 push합니다.
2. [Vercel 대시보드](https://vercel.com)에서 **Add New Project**를 선택하고 저장소를 연결합니다.
3. Framework Preset이 **Vite**로 자동 감지되면 별도 환경변수 설정 없이 바로 **Deploy** 버튼을 누릅니다.
4. 배포 완료 후 제공되는 Vercel 도메인(`https://<프로젝트명>.vercel.app`)을 통해 누구에게나 링크로 공유할 수 있습니다. (`vercel.json`의 rewrites를 통해 브라우저 CORS 문제 없이 실시간 기상청 데이터가 완벽 연동됩니다.)
